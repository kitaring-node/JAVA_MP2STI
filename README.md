Program Python sederhana untuk menampilkan lirik lagu "Pelangi" - HiVi! secara animasi di terminal. Efek pengetikan disesuaikan per karakter dan baris agar selaras dengan irama lagu.

Fitur Utama
1. Typing Effect
Menampilkan lirik huruf demi huruf seperti diketik secara real-time.

2. Dynamic Delay
Mengatur tempo pengetikan karakter dan jeda antarlirik agar pas dengan irama lagu.

3. Clean Output
Menggunakan `sys.stdout.flush()` untuk memastikan efek animasi berjalan mulus di terminal.


Prasyarat & Instalasi
Program ini murni menggunakan pustaka bawaan Python. 
1. Pastikan kamu sudah menginstal Python 3.x
2. Unduh atau salin kode program ke dalam file berformat `.py`

 Cara Menjalankan
Buka terminal atau command prompt, lalu jalankan perintah berikut:
```bash
python lirik_pelangi.py
